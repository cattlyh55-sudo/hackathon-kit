# 검증 기록

## 규칙
- 실제로 실행한 것만 기록한다. 실행하지 않은 항목은 결과 칸에 "미확인"이라고 쓴다.
- 실패해도 코드나 테스트를 고치지 않는다. 실패 내용을 그대로 기록하고 사용자에게 알린다.

## 절차
1. AGENTS.md의 실행·테스트 섹션에서 테스트 명령을 찾아 실행한다.
2. 사용자가 지정한 확인 항목(R번호, 성공 기준)이 있으면 각각 확인 명령을 실행한다.
   웹 서비스라면 0.0.0.0:3000으로 실행 중인지 확인하고, `curl -s localhost:3000/경로`로 주요 경로의 응답을 확인한다.
   화면을 눈으로 봐야 하는 항목은 결과 칸에 "사용자 직접 확인 필요"라고 적는다.
3. `git rev-parse --short HEAD`로 현재 커밋을 확인한다. 커밋되지 않은 변경이 있으면 "(미커밋)"이라고 함께 적는다.
4. docs/VERIFY.md 표에 `대상 | 확인 방법(실행한 명령) | 결과(통과/실패 수, 핵심 출력) | 커밋`을 추가하거나 갱신한다.
5. 사용자에게 통과/실패/미확인 개수를 3줄 이내로 보고한다.
