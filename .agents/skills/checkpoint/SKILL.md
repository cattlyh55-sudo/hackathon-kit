# 체크포인트 (읽기 전용)

## 규칙
- 아무 파일도 수정하지 않는다. 결과는 사용자에게만 보고한다.
- 사용자가 알려 준 경과 시간을 기준으로 판단한다. 모르면 먼저 묻는다.

## 절차
1. `git log --oneline`, `git diff --stat HEAD`, docs/PLAN.md, docs/REQUIREMENTS.md, docs/VERIFY.md를 확인한다.
2. 아래 세 가지를 각각 3줄 이내로 보고한다.
   - 진척: PLAN의 단계별 목표 경과 시간 대비 현재 위치, 남은 단계의 예상 소요 시간
   - 드리프트: R번호에 매핑되지 않는 파일·기능·라이브러리
   - 증거 없는 완료: 완료로 보이지만 VERIFY에 실행 기록이 없는 항목
3. 시간이 부족해 보이면 줄일 수 있는 범위를 1~2개 제안한다. 결정은 사용자가 한다.
